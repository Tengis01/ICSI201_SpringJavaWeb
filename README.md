# ICSI201_SpringJavaWeb

За лаборатор12 Spring framework + java буюу java кодыг сервер талд ажиллуулах ажил хийнээ.
Та 2 бас судалгаа хийж ойлголттой болж байгаа байхаа гэж бодож байна. 

Хийх ажилаа хувиарлая. Энэ удаагийх нилээд эвгүй лабораторын ажил байнэлээ (миний хувьд лав.) 
Энд голлох ажилыг би хийнэ. Голлох гэдэг нь үндсэн нийт кодоо хэвийн түвшинд барьж та 2ийн хийсэн зүйлсийг холбох засах бас турших зүйлс хийнэ.
Та 2 болохоор доорх 2ажилыг хувааж авах хэрэгтэй. 
- UI буюу html css дээр жижигхэн дизайн хийх энийг хийж байгаа хүн resources/templates дотор html
  file-аа үүсгэж хийнэ шүү өөр газар болохгүй.
  
- Яг үндсэн CRUD үйлдлийг бичих. Get Post Put Delete гээд 4нь үндсэн үйлдлээ бичих (яг үнэндээ гайгүй ажил шүү айж сүрдэх хэрэг байхгүй).
  Crud үйлдэлээ controllers folder дотор заавал бичнэ шүү өөр газар бичиж болохгүй

Өөрсдийн хийсэн зүйлээ localhost дээрээ ажиллуулж харахын тулд та 2т заавал mysql байх хэрэгтэй. Дараа нь application.properties file дотор байгаа
username password өөрсдийхөөрөө өөрчлөх хэрэгтэй мөн тэр port дугаар бас өөрчилж болно. хэрвээ mysql дахь passwordоо мартсан бол Server-ээ устгаад ахиад татаад
шинэ username password өгч болно шүү тэгэхдээ устгах гэж байгаа server чинь хэрэггүй database байвал хамаагүй. хэрэгтэй зүйл байвал өөр арга ашиглаарай.

mysql тохируулаад ч ажиллах арай болоогүй. учир нь гол холболтууд дутуу байгаа болохоор spring compiler хагас дутуу юм ажиллуулахгүй. тиймээс өөрсдийхөө хэсгийг     биччихээд ерөнхий болсон байх гээд найдаад л хүлээнэ гэсэн үг шүү. яг өөрсдийхөө хэсэгийг л push хийгээрээ.

MVC архитектурын баримталж байгаа болохоор тэр заасан газар кодоо бичээд үлдээчихээрээ.
